테마를 설치하고 설정하는 방법을 안내합니다.

이 테마는

KRDS의 헤더, 메인메뉴, 푸터, 브레드크럼, 사이드 내비게이션 등을 Jekyll 레이아웃으로 묶었습니다.

구성

  • default 기본 골격
  • home 첫 화면
  • page 일반 페이지
  • docs 사이드 메뉴가 있는 문서
  • blog, post 글 목록과 글
