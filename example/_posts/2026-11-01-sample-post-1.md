Gemfile 에 테마를 추가하고 `_config.yml` 에서 `theme: jekyll-theme-krds` 를 지정하면 바로 쓸 수 있습니다. 헤더, 메가 메뉴, 푸터와 같은 KRDS 구성요소가 기본으로 들어 있습니다.

## 먼저 확인할 것

Ruby 3.1 이상과 Jekyll 4 가 필요합니다. GitHub Pages 의 기본 빌더가 아니라 GitHub Actions 에서 빌드하세요.

[설치 안내](https://www.krds.go.kr)는 저장소의 README 를 따르면 됩니다.
