- **KRDS**: 행정안전부가 만든 범정부 UI/UX 디자인시스템. 이 사이트의 디자인 원본입니다.
- **디자인 토큰**: 색·간격 같은 디자인 값을 이름 붙여 모아 둔 CSS 변수입니다. [[디자인 토큰]] 문서를 보세요.
- **별칭**: 한 문서를 가리키는 다른 이름. `wiki_aliases`로 정합니다.
- **역링크**: 어떤 문서를 가리키는 다른 문서의 목록. 문서 아래 "이 문서를 가리키는 문서"에 나옵니다.
- **고아 문서**: 어떤 문서에서도 연결되지 않은 문서. 이 용어집 자체가 예시입니다. 위키 홈 아래 관리 목록에서 찾을 수 있습니다.
- **작성이 필요한 문서**: 링크는 있지만 아직 만들지 않은 문서. [[정보 상자]]처럼 만들어진 문서와 달리 붉은 점선으로 보입니다.
