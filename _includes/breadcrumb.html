{%- comment -%} KRDS 브레드크럼. - front matter에 breadcrumb: [{title, url}, ...] 가 있으면 그대로 쓴다. - 글(post)은 홈 > 블로그 > 제목. - 그 밖에는 URL 경로를 따라 올라가며 실제로 있는 페이지의 제목을 쓴다. {%- endcomment -%}
  1. 홈
    2. {%- if page.breadcrumb %} {%- for crumb in page.breadcrumb %}
  2. {{ crumb.title }}
    3. {%- endfor %} {%- elsif page.layout == 'post' and site.krds.blog_url %}
  3. {{ site.krds.blog_title | default: '블로그' }}
    4. {%- else %} {%- assign parts = page.url | split: '/' -%} {%- assign acc = '' -%} {%- for part in parts -%} {%- if part != '' and part contains '.' -%}{%- continue -%}{%- endif -%} {%- if part != '' -%} {%- assign acc = acc | append: '/' | append: part -%} {%- assign dir = acc | append: '/' -%} {%- unless dir == page.url -%} {%- assign found = site.pages | where: 'url', dir | first -%} {%- if found and found.title %}
  4. {{ found.title }}
    5. {%- endif -%} {%- endunless -%} {%- endif -%} {%- endfor %} {%- endif %} {%- if page.url != '/' %}
  5. {{ page.title }}
    6. {%- endif %}
